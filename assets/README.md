# Szenenbilder

Hier liegen die finalen nahezu fotorealistischen Bildassets für KC Küchen-Detektiv.

Einzelbild-Fälle: `kd-001.webp` bis `kd-020.webp`.

Fehlerbild-Modus:
- `kd-021-left.webp` / `kd-021-right.webp`
- `kd-022-left.webp` / `kd-022-right.webp`
- `kd-023-left.webp` / `kd-023-right.webp`

Empfohlenes Format: 16:9, mindestens 1600 × 900 Pixel. Die Unterschiede müssen klein, aber fair erkennbar sein.
